How it works

  • Gary is one model.glb file (glTF binary: the mesh and its textures together).
  • Three.js loads it with GLTFLoader; if a model has animations, the first one plays through an AnimationMixer (and a Pause button appears).
  • OrbitControls turns mouse and touch drags into camera moves.
  • No build step: Three.js comes from a CDN through an import map, and the page is hosted on GitHub Pages.
